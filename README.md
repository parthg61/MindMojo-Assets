# The Mind Mojo — Brand Assets

Colours: Ink `#19202d` · Mojo Pink `#eb6a80` · Gold `#fbae18` · White `#fdfdfd`

Use FullColour on light backgrounds, Reversed (white text/hat) on dark ones, Mono_* when one colour is needed.

Favicon: 16px uses the hat + brain silhouette; 32px and up use the full icon.
